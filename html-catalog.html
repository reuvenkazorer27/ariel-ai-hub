קטלוג ויזואלי Power BI

HTML Content · DAX · לכל ויזואל מובנה

גרסת HTML לכל ויזואל מובנה של Power BI — מדד DAX שמחזיר HTML ומוצג דרך הוויזואל HTML Content. כל פריט מוצג חי עם נתוני דוגמה, מגיב לסלייסר של העמוד כמו בדוח אמיתי, ומגיב לפאנל הסגנון: הצבעים, הפורמט והמצב שתבחרו נצרבים גם ל-DAX וגם לפרומפט שמועתקים.

1

התקנת הוויזואל

ב-Power BI Desktop: Get more visuals ← חיפוש HTML Content (מאת Daniel Marsh-Patrick) ← הוספה.

2

בחירת סגנון

בפאנל הסגנון בוחרים צבעים, פלטה, פורמט מספרים וכיוון. כל התצוגות מתעדכנות מיד.

3

העתקה והתאמה

העתק DAX נותן את הקוד עם הצבעים שבחרתם. העתק פרומפט מוסיף הנחיה לצ'אט AI שיתאים לשמות במודל שלכם.

4

הצבה בדוח

גוררים את המדד ל-Values של הוויזואל. לפריטים המסומנים ב-JS צריך Allow scripts.
