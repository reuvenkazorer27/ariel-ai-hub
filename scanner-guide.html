מסלול א׳

התקנה כ-plugin

כשהארגון מאפשר תוספים. ב-Cowork זו גרירה אחת; ב-Claude Code זו פקודת /plugin.

  1. Cowork (דסקטופ) - הדרך הקצרה

    גררו את קובץ ה-.plugin לצ'אט בדסקטופ ואשרו בכפתור ההתקנה. אם זה עבד - דלגו ישר אל אחרי ההתקנה.

  2. חילוץ ה-ZIP למקום קבוע

    קליק ימני על הקובץ שהורדתם ← Extract All, למקום שלא יזוז, למשל:

    C:\Users\User\claude-plugins\powerbi-marketplace
    ✅ בדיקה

    בתוך התיקייה שחולצה יש תיקייה .claude-plugin ובתוכה marketplace.json.

  3. הוספת המרקטפלייס ב-Claude Code

    /plugin marketplace add C:\Users\User\claude-plugins\powerbi-marketplace
    שימו לב

    מקלידים ב-Claude Code, לא בצ'אט הרגיל - רק שם /plugin עובד.

  4. התקנה

    /plugin install powerbi-report-reviewer@local-powerbi

    אשרו אם מופיעה בקשה. לחלופין: הקלידו /plugin ← Browse marketplaces ← local-powerbi ← Install.

מסלול ב׳

התקנה ידנית - העתקת תיקייה

כש-skills נטענים אבל /plugin חסום. בלי שום פקודה.

  1. חילוץ ה-ZIP

    קליק ימני ← Extract All. מקבלים תיקייה בשם powerbi-report-reviewer - זו התיקייה שנעתיק.

  2. איתור תיקיית התוספים

    C:\Users\User\.claude\plugins
    איך מגיעים לשם

    הדביקו את הנתיב בשורת הכתובת של סייר הקבצים ולחצו Enter. אם plugins חסרה - צרו אותה. תיקיית .claude מוסתרת: View ← Show ← Hidden items.

    ⚠️ שימו לב

    אם הארגון הגדיר תיקיית תוספים אחרת - השתמשו בזו שהם נתנו.

  3. העתקה, הדבקה והפעלה מחדש

    העתיקו את התיקייה powerbi-report-reviewer אל תיקיית היעד. המבנה הסופי חייב להיות:

    ...\.claude\plugins\powerbi-report-reviewer\
   ├─ .claude-plugin\plugin.json    <- חייב להיות שם
   └─ skills\
        ├─ powerbi-report-reviewer\
        └─ powerbi-design-search\

    סגרו את Claude Code ופתחו מחדש.

    ✅ בדיקה

    מופיעים שני הכלים: הסוקר וחיפוש העיצוב.

מסלול ג׳

אין skills? בלי התקנה, דרך CLAUDE.md

כשהארגון חוסם skills לגמרי. כל הכלים נשמרים בעומק מלא - מגדירים פעם אחת, ואז זה עובד בכל פרויקט. CLAUDE.md נטען אוטומטית כ"זיכרון פרויקט" ואינו skill, ולכן עובד גם כששאר המנגנונים חסומים.

  1. חילוץ ה-ZIP ושמירת תיקיית הכלים במקום קבוע

    בתוך ה-ZIP יש שני דברים שרלוונטיים כאן: התיקייה powerbi-report-reviewer (עם skills\) והקובץ CLAUDE.example.md. העתיקו את התיקייה למקום אחד קבוע, למשל:

    C:\Users\User\powerbi-toolkit\powerbi-report-reviewer

  2. הצבת CLAUDE.md בתיקיית הפרויקט

    העתיקו את CLAUDE.example.md לשורש תיקיית פרויקט ה-Power BI, שנו את שמו ל-CLAUDE.md, ועדכנו בתוכו את שורת ה-TOOLKIT לנתיב שבחרתם בשלב 1.

    ⚠️ אל תדביקו את תוכן הקובץ לצ'אט

    הודעה שמתחילה ב-# מפעילה ב-Claude Code את פקודת הזיכרון. יוצרים ועורכים את הקובץ בסייר הקבצים או בעורך טקסט - לא בצ'אט.

    מה זה עושה

    CLAUDE.md אומר ל-Claude: "קרא את הקבצים תחת TOOLKIT ופעל לפיהם" - כך הוא משתמש בכל ה-references, ה-DAX, הקטלוג וה-CSV, בדיוק כמו skill מלא.

  3. פשוט מבקשים

    פתחו את הפרויקט ב-Claude Code וכתבו "בקר לי את הדוח". Claude יקרא את הכלים המלאים מהתיקייה ויפעל לפיהם.

    ✅ התוצאה

    אותו עומק כמו התקנת plugin - בלי להתקין skills.

אחרי ההתקנה - איך מתחילים לעבוד

בכל שלושת המסלולים, אחרי ההתקנה צריך לפתוח סשן ב-Claude Code על תיקיית הפרויקט של הדוח. הדוח חייב להיות כבר מפורק לפורמט PBIP - תיקייה עם קובץ .pbip, תיקיית .Report ותיקיית .SemanticModel - ולא קובץ .pbix בודד.

אין לכם PBIP?

ב-Power BI Desktop: File ← Save as ← שמירה כ-Power BI project (.pbip). זה מפרק את הדוח לקבצי טקסט שהכלי יודע לקרוא.

פתחו את תיקיית הפרויקט ב-Claude Code (Open folder), ואז כתבו:

בקר לי את הדוח ותן סיכום ביקורת

פניות חלופיות: "עבור על הדוח ותן סיכום ביקורת" · "בקר לי את ה-PBIP" · "מה חסר בדשבורד"

✅ מה קורה אז

הכלי ישאל אם מדובר בדוח רגיל או מתקדם (רגיל ~10 דקות, מתקדם עד ~45 דקות) ויתחיל לעבוד על ה-PBIP.
