התקנת Power Viz ל-VS Code

לפתוח, לסקור ולערוך דוחות Power BI כקוד - עם הנתונים האמיתיים, אופליין, בלי Power BI Desktop.

Windows · macOS · Linux VS Code 1.106+ בלי Power BI Desktop Preview - בפיתוח פעיל
00

בקצרה, בסרטון

45 שניות: מתקינים, פותחים תיקיית PBIP, והדוח נפתח בתצוגה חיה בתוך VS Code. לוחצים על ויזואל ורואים את השדות שלו, ומבקשים מה-AI שינוי בשפה חופשית.

01

לפני שמתחילים

  • VS Code 1.106 ומעלה. גרסה ישנה יותר לא תטען את התוסף.
  • Git מותקן - נדרש רק כדי להשוות גרסאות (Visual diff ותצוגת Changes). בלעדיו כל השאר עובד.
  • קובץ לעבוד עליו - קובץ .pbip, תיקיית *.Report, או .pbix / .pbit שאפשר להמיר.
  • לא נדרש - Power BI Desktop, חשבון Power BI, או חיבור לאינטרנט. הכול רץ מקומית.
02

התקנה

  1. פתח את Extensions בסרגל הצד.
    קיצור: Ctrl+Shift+X (ב-Mac: Cmd+Shift+X)
  2. חפש Power Viz ובחר את Power Viz — Power BI Projects.
    המפרסם הוא Afzal Khan. יש כמה תוספים עם שם דומה - ודא את שם המפרסם.
  3. לחץ Install.
    הכפתור מתחלף ל-Disable / Uninstall כשההתקנה הסתיימה.

לחלופין, משורת הפקודה:

code --install-extension afzalkhan.power-viz
איך יודעים שזה עבד אייקון Power BI חדש מופיע ב-Activity Bar. לחיצה עליו פותחת את התצוגות Projects ו-Changes. אם האייקון לא מופיע, טען את החלון מחדש: Developer: Reload Window מתוך ה-Command Palette.
כדאי להשאיר דלוק התוסף בשלב Preview ובפיתוח פעיל, אז Auto Update שווה את זה. תקלות ובקשות נשלחות דרך לשונית ה-Q&A בדף התוסף.
03

הפרויקט הראשון

פתח תיקייה, לא קובץ בודד. זו הטעות הנפוצה בפעם הראשונה: Power Viz מחפש פרויקט, והפרויקט הוא תיקייה.

HR & People.pbip          ← the project file
HR & People.Report/       ← pages, visuals, theme
  definition.pbir
  definition/pages/…/visual.json
HR & People.SemanticModel/ ← tables, measures (TMDL)
  1. File → Open Folder, ובחר את התיקייה שמכילה את ה-.pbip.
  2. לחץ על אייקון Power BI. הפרויקט יופיע תחת Projects, עם Report ו-Semantic model.
  3. הרחב את Report ולחץ על עמוד - התצוגה המקדימה נפתחת.
    אפשר גם: Power Viz: Open Report Preview מה-Command Palette.
  4. לחץ על ויזואל כדי לראות את השדות והאזהרות שלו.
    לחיצה כפולה פותחת את ה-visual.json שלו. עם Follow active editor דלוק, פתיחת קובץ כזה בוחרת את הוויזואל בתצוגה.

אין לך פרויקט PBIP?

  • ב-Power BI Desktop: File → Save as → Power BI project.
  • ב-VS Code: לחיצה ימנית על קובץ .pbix ב-Explorer ← Power Viz: Convert .pbix to PBIP Project…

קבצי .pbix ו-.pbit נפתחים לתצוגה לקריאה בלבד. כדי לערוך אותם צריך להמיר ל-PBIP. ה-.pbix המקורי נשמר בזיכרון, כך שהתצוגה ממשיכה להציג את הנתונים שלו.

04

ברירת המחדל היא Local data: הערכים מפוענחים מתוך ה-.pbix ומחושבים במנוע DAX מובנה, על המחשב שלך. אין חיבור לשום מקום.

05

הגדרת ה-AI

יש שלוש דרכים נפרדות, ואפשר להפעיל יותר מאחת. בכל אחת מהן כל עריכה של ה-AI היא שינוי קובץ רגיל שאפשר לסקור ב-Visual diff לפני שמשאירים אותו.

צ'אט מובנה

הכפתור Ask AI על כל עמוד, ויזואל או אובייקט במודל. בוחרים ספק בפאנל: Claude או GitHub Copilot.

ל-Claude צריך מפתח Anthropic:

Power Viz: Set Anthropic API Key…
איפה המפתח נשמר ב-secret storage של VS Code, אף פעם לא בקובצי ההגדרות. הדגם נקבע בהגדרה powerViz.ai.claudeModel, והספק בברירת מחדל ב-powerViz.ai.provider.

GitHub Copilot

הכלים של Power Viz זמינים ב-Copilot agent mode, והמשתתף @powerviz עובד ב-Copilot Chat עם /edit, /review ו-/explain. אין מה להגדיר.

Claude Code, Cursor ו-agent hosts אחרים

ל-Claude Code, הרץ פעם אחת לכל workspace:

Power Viz: Configure Claude Code for This Workspace…

זה מוסיף ל-workspace את שרת ה-MCP של Power Viz ומיומנות לעריכת דוחות. הרץ שוב אחרי כל עדכון של התוסף. ל-Cursor ול-Copilot agent mode השרת מוצע אוטומטית בתיקיות שמכילות פרויקט Power BI, כל עוד powerViz.mcp.enable דלוק.

07

מה לבדוק כשמשהו לא עובד

  • אין אייקון Power BI - גרסת VS Code ישנה מ-1.106, או שצריך Developer: Reload Window.
  • "No Power BI project found" - נפתח קובץ ולא תיקייה, או שהתיקייה לא מכילה .pbip / *.Report.
  • אין Visual diff - Git לא מותקן, או שהתיקייה אינה מאגר Git. בנוסף, ההשוואה והפריסה מושבתות ב-Restricted Mode.
  • הערכים נראים לא נכונים - התצוגה מסמנת ויזואלים כ-Approximate כשמנוע ה-DAX המובנה לא תומך בפונקציה. למדידה מדויקת השתמש ב-Live mode.
  • מפות או ויזואלים מותאמים ריקים - מפות, ויזואלי AI וויזואלים מותאמים מוצגים כמצייני מקום בתצוגה האופליינית. זו התנהגות מתוכננת.
  • העיצוב לא זהה ל-Power BI - התצוגה קרובה מאוד אבל אינה העתק מדויק לפיקסל. Live mode מציג את הדוח כפי שהשירות מרנדר אותו.
פרטיות הרינדור, הוולידציה, ההמרה וההשוואה קורים על המחשב שלך, ונתוני הדוח לא יוצאים ממנו. אין טלמטריה. בקשות רשת קורות רק כשאתה בעצמך משתמש ביכולת ענן: התחברות ל-Power BI או Fabric, צ'אט עם Claude או Copilot (התוכן שנשלח מגיע לספק), ו-Publish Sandbox - היחידה שמעלה את ה-.pbix כולו, ורק אחרי אישור שלך.
