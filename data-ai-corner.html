POWER BI

החידוש המעניין: המודל מגן על עצמו ממספרים מטעים

הבעיה: בכל מודל יש טבלאות שאין ביניהן Relationship - למשל טבלת תקציב מול טבלת מכירות. אם בונה הדוח גורר לטבלה אחת את עמודת החנות מהתקציב ואת מדד המכירות, Power BI לא מתריע. הוא פשוט מציג את סך כל המכירות בכל שורה, שוב ושוב - נכון חשבונית, אבל מטעה.

הפתרון: Calculation Group עם noSelectionExpression שרץ אוטומטית על כל מדד. בודק אם המדד והעמודה שעל הציר שייכים לאותו עולם (ISSELECTEDMEASURE + ISINSCOPE) - ואם לא, מחזיר "###" במקום מספר מטעה. ב-Total השורה כבר לא ב-scope, אז המדד מוצג כרגיל.

VAR IsSalesMeasure =
    ISSELECTEDMEASURE ( [Revenue], [Qty Sold], [Orders] )
VAR BudgetColumnInScope =
    ISINSCOPE ( 'Store Budgets'[Store] )
        || ISINSCOPE ( 'Store Budgets'[Month] )
RETURN
IF (
    IsSalesMeasure && BudgetColumnInScope,
    "###",
    SELECTEDMEASURE ()
)

POWER BI

מיקרו-ויז'ואלים בתוך טבלה, בלי ויז'ואל מותאם

טבלה רגילה, ובעמודה האחרונה שלה גלולת סטטוס צבעונית (נקודה + אחוז) שמשתנה משורה לשורה לפי הנתון - בלי להתקין שום Custom Visual.

שלב 1 - מדד שמחזיר מחרוזת SVG (טקסט שמצייר תמונה), עם צבע וערך מחושבים מנתוני השורה:

StatusPill =
VAR pct = [שינוי אחוז]
VAR c = IF ( pct >= 0.03, "green", IF ( pct <= -0.05, "red", "orange" ) )
RETURN
    "data:image/svg+xml;utf8,"
        & "<svg xmlns='http://www.w3.org/2000/svg' width='100' height='24'>"
        & "<circle cx='10' cy='12' r='6' fill='" & c & "'/>"
        & "<text x='22' y='16' font-size='12'>" & FORMAT ( pct, "0.0%" ) & "</text></svg>"

שלב 2 - בוחרים את המדד וב-Data category מסמנים Image URL (בלי זה יוצג טקסט גולמי). שלב 3 - גוררים למטריקס/טבלה כמו שדה רגיל.

מה אפשר לצייר ככה: sparklines, פסי התקדמות, נוריות סטטוס, כרטיסי KPI - הכול בתוך שורת הטבלה. לתחזוקה נוחה: תבנית SVG אחת עם פרמטרים, או חבילת DaxLib.SVG המתקינה פונקציות מוכנות דרך TMDL view.
